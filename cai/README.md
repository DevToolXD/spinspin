# 🧩 CAI 하네스

API 키를 넣으면 **Claude · GPT · Gemini** 를 **CTF·모의해킹 특화 레드팀 하네스**로 굴리는
브라우저 전용 콘솔입니다. 여러 API 를 등록하면 **조별과제처럼 한 팀으로 토론**하며 하나의
챌린지를 함께 공략합니다. 로그인하면 API 키와 대화 세션이 암호화되어 저장됩니다.

서버가 없습니다. 정적 파일만으로 동작하며 GitHub Pages 에 그대로 배포됩니다.

👉 **https://devtoolxd.github.io/spinspin/cai/**

> ⚠️ **인가 범위**: CTF, 본인 소유 랩, 서면으로 허가받은 모의해킹 대상에만 사용하세요.
> 하네스 프롬프트가 그 경계를 명시합니다. 그 밖의 시스템에 대한 공격은 불법입니다.

## 1:1 모드 — 레드팀 하네스

정찰 → 열거 → 취약점 분석 → 익스플로잇/PoC → 포스트익스플로잇 → 리포트로 이어지는 공격
보안 방법론을 시스템 프롬프트로 씌워, 어느 모델이든 같은 방식으로 움직이게 합니다.

| 하네스 프리셋 | 초점 |
|--------------|------|
| **CAI 레드팀** (기본) | CTF·모의해킹 전반 (웹·pwn·리버싱·크립토·포렌식·네트워크) |
| **CAI 웹 익스플로잇** | SQLi·XSS·SSRF·IDOR·SSTI·역직렬화 등 웹 취약점 |
| **CAI Pwn / 리버싱** | 바이너리 익스플로잇·RE (보호기법·pwntools·ROP) |
| **CAI 크립토 / 포렌식** | 암호 공격·인코딩·스테가노·포렌식 |
| **CAI 블루팀 / DFIR** | 로그·아티팩트 분석, IOC, 증거 보존 (방어) |
| **범용 / 하네스 없음 / 직접 작성** | 일반 작업, 모델 본래 동작 비교, 프롬프트 직접 작성 |

설정 → 하네스 탭에서 전문을 읽고 고칠 수 있습니다.
치환 변수: `{{DATE}} {{PROVIDER}} {{MODEL}} {{USER}} {{TOOLS}} {{MEMORY}}`

### 브라우저에서 실제로 하는 일

이 서비스는 대상 시스템에 직접 명령을 쏘지 않습니다(브라우저 제약). 대신:

- 페이로드·익스플로잇·PoC·pwntools 스크립트를 **작성**하고,
- 검증 가능한 로직(디코더·파서·오프셋 계산·암호 공격·JWT 조작)을 **`run_javascript` 샌드박스에서 실제 실행**해 확인하고,
- 사용자가 붙여넣은 대상 출력(스캔 결과·디스어셈블·응답)을 **분석**하고,
- 접근 가능한 엔드포인트는 `fetch_url` 로 살펴봅니다(CORS 허용 대상).

즉, 사용자가 자기 환경에서 실제 도구(nmap·gdb 등)를 돌리고 그 출력을 넘기면, 하네스가
다음 수를 판단해 주는 **협력형**입니다.

## 👥 팀 모드 — 레드팀 조별과제

여러 AI 를 **조원**으로 등록하면(다른 제공자든, 같은 제공자 여럿이든), 상단 **👥 팀** 모드에서
조별과제처럼 함께 토론합니다.

- 한 메시지를 보내면 조원들이 **순서대로 한 라운드씩** 발언합니다.
- 각 조원은 지금까지의 대화(사용자 + 다른 조원의 발언)를 보고 **반응**합니다 — 동의·반박·보완.
- 조원마다 **역할**(웹/pwn/크립토/…)을 나눠 맡아 자기 관점으로 기여합니다.
- **🔁 한 라운드 더 토론** 버튼으로 추가 라운드를 돌립니다.
- **⚙️ 설정 → 팀 → “등록된 키로 자동 구성”** 이면 등록된 제공자로 레드팀이 한 번에 짜입니다.

설정에서 조원마다 이름·제공자·모델·역할·색을 지정하고, 공동 목표(챌린지 설명)를 넣을 수 있습니다.
팀 모드에서는 도구 실행 대신 토론·산출물 작성에 집중합니다.

## 도구 (1:1 모드)

에이전트 루프는 `모델 → 도구 호출 → 실행 → 결과를 다시 모델에` 를 반복합니다(단계 제한).

| 도구 | 하는 일 |
|------|---------|
| `run_javascript` | Web Worker 에서 JS 실행 — PoC·디코더·암호 공격·계산 검증 (8초 타임아웃) |
| `write_file`/`read_file`/`list_files`/`delete_file` | 암호화된 가상 작업공간 (관찰·리포트 저장) |
| `remember`/`recall` | 장기 기억. 저장 내용은 매 대화 시스템 프롬프트에 자동 주입 |
| `fetch_url` | URL 본문 읽기 (CORS 허용 대상) |
| `show_artifact` | 결과물(HTML·SVG·마크다운)을 오른쪽 미리보기 패널에 렌더링 |

## 지원 제공자

| 제공자 | 엔드포인트 | 키 발급 |
|--------|-----------|---------|
| Claude | `POST /v1/messages` (SSE) | [console.anthropic.com](https://console.anthropic.com/settings/keys) |

| Gemini | `:streamGenerateContent` (SSE) | [aistudio.google.com](https://aistudio.google.com/app/apikey) |

키를 넣고 **확인**을 누르면 각 제공자의 모델 목록을 실제로 받아와 드롭다운을 채웁니다.
대화는 Anthropic 형식을 정본으로 두고 OpenAI/Gemini 형식으로 변환하며, 도구 스키마·파라미터
차이(예: o-시리즈의 `max_completion_tokens`)도 어댑터가 흡수합니다.

## 로그인과 저장

서버가 없으므로 계정은 **이 브라우저 안에서만** 존재합니다.

```
비밀번호 ──PBKDF2(SHA-256, 250,000회)──▶ AES-GCM 256bit 키 (메모리에만)
                    │
      ┌─────────────┼──────────────┬────────────────┐
      ▼             ▼              ▼                ▼
  API 키·설정    대화 세션     팀 로스터        작업공간·기억
      └──────────── IndexedDB 에 암호문으로 저장 ────────────┘
```

- 비밀번호는 저장되지 않습니다. **분실 시 복구 불가.**
- 계정별로 세션·키·팀·파일이 격리됩니다.
- 비밀번호를 바꾸면 저장된 모든 데이터를 새 키로 재암호화합니다.
- API 호출은 브라우저에서 제공자로 직접 전송됩니다(중간 서버 없음).
- 대화는 JSON 으로 내보내고 다른 브라우저에서 가져올 수 있습니다.

> ⚠️ 공용 PC 에서는 사용 후 설정 → 계정 → **계정과 모든 데이터 삭제**를 권장합니다.

## 실행

정적 파일이라 빌드가 필요 없지만, **보안 컨텍스트**가 필요합니다(WebCrypto·IndexedDB·Web
Worker 를 씁니다 — `file://` 로 열면 동작하지 않습니다).

```bash
npx serve .        # → http://localhost:3000/cai/
```

또는 배포된 주소를 그대로 사용하세요: https://devtoolxd.github.io/spinspin/cai/

## 파일 구성
