# 🎯 랜덤 추첨 룰렛 (spinspin)

시작 버튼을 **꾹 누르고 있으면** 룰렛이 점점 빨라지고, 버튼을 **떼면** 멈추는 추첨 웹앱입니다.

## 사용법

`index.html` 파일을 브라우저에서 열기만 하면 됩니다. (별도 설치/빌드 불필요)

1. 시작 버튼을 길게 누르면 룰렛이 가속하며 돌아갑니다.
2. 버튼을 떼면 서서히 감속하며 멈춥니다.
3. 멈춘 위치의 참가자가 당첨됩니다.
4. `⚙️ 참가자 설정`에서 참가자 명단을 자유롭게 바꿀 수 있습니다.

## ⚠️ 조작(rigged) 기능

겉보기에는 무작위로 돌아가지만, 실제로는 **항상 2번째 칸이 100% 당첨**되도록 만들어져 있습니다.

- `script.js` 상단의 `RIGGED_INDEX` 값으로 당첨 칸을 조절합니다.
- `0` = 첫 번째 칸, `1` = 두 번째 칸(기본값), `2` = 세 번째 칸 ...

## 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 화면 구조 |
| `style.css` | 디자인/애니메이션 |
| `script.js` | 룰렛 회전 로직 및 당첨 조작 |
