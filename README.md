# 🎯 랜덤 추첨 룰렛

시작 버튼을 **꾹 누르고 있으면** 룰렛이 점점 빨라지고, 버튼을 **떼면** 멈추는 추첨 웹앱입니다.

## 사용법

`index.html` 파일을 브라우저에서 열기만 하면 됩니다. (별도 설치/빌드 불필요)

1. 시작 버튼을 길게 누르면 룰렛이 가속하며 돌아갑니다.
2. 버튼을 떼면 서서히 감속하며 멈춥니다.
3. 멈춘 위치의 참가자가 당첨됩니다.
4. `⚙️ 참가자 설정`에서 참가자 명단을 자유롭게 바꿀 수 있습니다.

## ⚠️ 조작(rigged) 기능

겉보기에는 무작위로 돌아가지만, 실제로는 **항상 2번째 칸이 100% 당첨**되도록 만들어져 있습니다.

- `script.js` 상단의 `RIGGED_INDEX` 값으로 당첨 칸을 조절합니다.
- `0` = 첫 번째 칸, `1` = 두 번째 칸(기본값), `2` = 세 번째 칸 ...

## 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 화면 구조 |
| `style.css` | 디자인/애니메이션 |
| `script.js` | 룰렛 회전 로직 및 당첨 조작 |

# 🧩 CAI 하네스

API 키를 넣으면 **Claude · GPT · Gemini** 를 같은 에이전트 하네스로 굴리는 브라우저 전용 콘솔입니다.
로그인하면 API 키와 대화 세션이 비밀번호로 암호화되어 브라우저에 저장되고, 다시 접속하면 그대로 이어집니다.

- 제공자 3종 통합 — 대화 형식·도구 스키마·스트리밍을 어댑터가 변환
- 하네스 프리셋 5종 (기본 / 코더 / 리서치 / 없음 / 직접 작성) — 전문을 직접 고칠 수 있음
- 브라우저 내 도구 9종 — JS 샌드박스 실행, 가상 파일시스템, 장기 기억, URL 읽기, 결과물 미리보기
- 로컬 계정 로그인 — PBKDF2 + AES-GCM, 계정별 데이터 격리, 대화 내보내기/가져오기
- 외부 라이브러리·CDN·빌드 도구 없음

자세한 내용은 **[cai/README.md](cai/README.md)** 를 보세요.
