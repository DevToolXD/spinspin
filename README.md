# 🎯 랜덤 추첨 룰렛 (spinspin)

시작 버튼을 **꾹 누르고 있으면** 룰렛이 점점 빨라지고, 버튼을 **떼면** 멈추는 추첨 웹앱입니다.

## 사용법

`index.html` 파일을 브라우저에서 열기만 하면 됩니다. (별도 설치/빌드 불필요)

1. 시작 버튼을 길게 누르면 룰렛이 가속하며 돌아갑니다.
2. 버튼을 떼면 서서히 감속하며 멈춥니다.
3. 멈춘 위치의 참가자가 당첨됩니다.
4. `⚙️ 참가자 설정`에서 참가자 명단을 자유롭게 바꿀 수 있습니다.

## ⚠️ 조작(rigged) 기능

겉보기에는 무작위로 돌아가지만, 실제로는 **항상 2번째 칸이 100% 당첨**되도록 만들어져 있습니다.

- `script.js` 상단의 `RIGGED_INDEX` 값으로 당첨 칸을 조절합니다.
- `0` = 첫 번째 칸, `1` = 두 번째 칸(기본값), `2` = 세 번째 칸 ...

## 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 화면 구조 |
| `style.css` | 디자인/애니메이션 |
| `script.js` | 룰렛 회전 로직 및 당첨 조작 |

# ⏱ 스톱워치 · 타이머 (stopwatch.html)

붓글씨 숫자로 1/100초까지 보여주는 스톱워치와 타이머입니다. `stopwatch.html` 하나만 브라우저에서 열면 됩니다.
글꼴까지 파일 안에 들어 있어서 인터넷 연결 없이도 그대로 동작합니다.

| 기능 | 설명 |
|------|------|
| 1/100초 표시 | 흰 배경에 검은 붓글씨. 초 아래 두 자리는 한 단계 작게 놓아 읽는 자리와 구분됩니다 |
| 배경 사진 | `배경 사진` 버튼, 화면에 끌어다 놓기, 붙여넣기(⌘/Ctrl+V) 모두 됩니다. 밝기 슬라이더로 글씨가 묻히지 않게 조절합니다 |
| 전체 화면 | `전체 화면` 버튼 또는 <kbd>F</kbd> |
| 랩 | 구간마다 기록이 쌓이고 가장 빠른/느린 구간이 표시됩니다 |

시작을 누르면 숫자만 남고 버튼·안내 문구가 모두 사라집니다.
마우스를 움직이거나 키를 누르면 다시 나타나고, 손을 떼면 잠시 뒤 또 사라집니다.
전체 화면이 아니어도 똑같이 동작합니다.

단축키: <kbd>Space</kbd> 시작·정지 · <kbd>L</kbd> 랩 · <kbd>R</kbd> 초기화 · <kbd>F</kbd> 전체 화면

시간은 `performance.now()` 기준으로 재고, 표시할 때 반올림이 아니라 버림을 씁니다.
화면에 `10.00`이 보이면 실제로 10초가 지난 것입니다.

## 타이머

상단에서 `타이머`로 바꾸면 됩니다. 프리셋을 누르거나 숫자를 직접 입력합니다
(전자레인지처럼 오른쪽부터 채워집니다. `1` `2` `3` `4` → 12분 34초).

평소에는 스톱워치와 똑같이 조용합니다. **10초가 남으면 달라집니다.**

| 남은 시간 | 일어나는 일 |
|-----------|-------------|
| 10초 → 0초 | 숫자가 흔들리기 시작하고, 화면 뒤에서 유리가 갈라져 나옵니다. 갈라짐은 점점 길어지고 가장자리 빛이 빠집니다. 저음이 깔리고 심장 박동이 빨라집니다 |
| 0초 | 화면이 산산조각 나며 우주로 떨어집니다 |
| 이후 | 작은 별들이 반짝이고 가운데 큰 별이 천천히 돌다가 확 빨라집니다. 카메라가 드론처럼 훑고 지나가며 화면이 흔들리고, 레터박스가 닫히면서 제목이 뜨고 엔딩 크레딧이 올라갑니다 |

전체 길이는 약 35초입니다. **아무 키나 누르거나 화면을 클릭하면 바로 건너뜁니다.**

소리는 WebAudio로 그 자리에서 만들어 냅니다(오디오 파일 없음). 상단 `소리` 버튼으로 끌 수 있습니다.
`prefers-reduced-motion`이 켜져 있으면 흔들림과 파편을 줄여서 재생합니다.
