# 🎯 조준 보조 (Aim Assist) — Roblox LocalScript

UI 패널의 **ON** 버튼으로 기능을 켠 뒤, **마우스 우클릭을 누르고 있는 동안에만** 가장 가까운 플레이어의 **머리(Head)** 를 향해 카메라가 조준됩니다. 버튼을 놓으면 곧바로 기본 카메라 조작으로 돌아갑니다.

> 본인이 만든 게임에 넣는 조준 보조(락온) 기능입니다. 남의 게임에 주입해서 쓰는 건 Roblox 이용 약관 위반입니다.

## 설치 방법

1. Roblox Studio에서 **Explorer** 창을 엽니다.
2. `StarterPlayer` → `StarterPlayerScripts` 를 찾습니다.
3. `StarterPlayerScripts` 에 우클릭 → **Insert Object** → **LocalScript** 를 추가합니다.
4. 새로 만든 LocalScript의 이름을 `AimAssist` 로 바꿉니다.
5. [`AimAssist.client.lua`](./AimAssist.client.lua) 내용을 전부 복사해서 붙여넣습니다.
6. **Play** 를 눌러 테스트합니다.

> 파일 이름의 `.client.lua` 는 Rojo에서 LocalScript를 뜻하는 규칙입니다. Studio에 직접 붙여넣을 거라면 신경 쓰지 않아도 됩니다.

### 테스트할 때 참고

혼자 플레이하면 조준할 상대가 없습니다. Studio 상단 **Test** 탭 → **Clients and Servers** 에서 플레이어 수를 2명 이상으로 놓고 **Start** 하면 실제로 동작을 확인할 수 있습니다.

## 조작

| 동작 | 방법 |
|------|------|
| 기능 켜기 / 끄기 | 패널의 `ON` / `OFF` 버튼, 또는 `Q` 키 |
| **조준** | **마우스 우클릭을 누르고 있는 동안** |
| 패널 옮기기 | 패널 배경을 드래그 |

패널은 기본적으로 화면 **오른쪽 위**에 뜨고, 현재 조준 중인 대상 이름과 거리가 표시됩니다.

`ON` 은 기능을 켜는 마스터 스위치일 뿐입니다. 켜져 있어도 우클릭을 누르지 않으면 카메라를 전혀 건드리지 않습니다.

우클릭을 누르고 있는 동안 대상을 한 번 잡으면, 그 대상이 죽거나 `DropDistance`(기본 800스터드)보다 멀어지기 전까지는 더 가까운 사람이 나타나도 계속 그 사람만 조준합니다. 버튼을 놓으면 대상이 해제되고, 다시 누르면 **그 시점의** 가장 가까운 상대를 새로 잡습니다. (놓아도 대상을 기억하게 하려면 `KeepTargetOnRelease` 를 `true` 로 바꾸세요.)

## 설정

스크립트 맨 위의 `CONFIG` 값만 바꾸면 됩니다.

| 값 | 기본값 | 설명 |
|----|--------|------|
| `StartEnabled` | `false` | `true` 면 게임 시작하자마자 ON 상태 |
| `ToggleKey` | `Enum.KeyCode.Q` | 켜고 끄는 단축키 (`nil` 이면 버튼만 사용) |
| `HoldToAim` | `true` | `true` 면 아래 버튼을 누르고 있는 동안에만 조준. `false` 면 ON인 동안 계속 조준 |
| `AimButton` | `Enum.UserInputType.MouseButton2` | 조준을 거는 버튼 (기본: 우클릭) |
| `KeepTargetOnRelease` | `false` | `true` 면 버튼을 놓아도 대상을 기억했다가 다시 조준 |
| `AimPartName` | `"Head"` | 조준할 부위. `"HumanoidRootPart"` 로 바꾸면 몸통 조준 |
| `MaxDistance` | `300` | **새 대상을 고를 때** 이 거리(스터드) 밖은 무시 |
| `DropDistance` | `800` | **이미 조준 중인 대상**은 이만큼 멀어져야 놓아줌 |
| `TeamCheck` | `true` | 같은 팀은 대상에서 제외 (새로 고를 때만 적용) |
| `WallCheck` | `false` | 벽에 가려진 대상은 제외 (새로 고를 때만 적용). **아래 주의사항 참고** |
| `Smoothness` | `0` | `0` 이면 즉시 조준(스냅). 값을 올릴수록 부드럽게 따라감 (`14` 정도면 약 0.2초) |
| `RotateCharacter` | `false` | `true` 면 캐릭터 몸통도 대상 쪽으로 회전 |
| `Debug` | `false` | `true` 면 대상 탐색 결과를 Output 창에 매번 출력 |

> **`WallCheck` 주의** — 레이캐스트는 `CanCollide` 가 꺼진 장식물이나 투명 파트에도 걸립니다 (`CanQuery` 가 켜져 있으면 잡힘). 맵에 따라 "분명히 보이는데 계속 벽에 가렸다고 나오는" 상황이 생기기 때문에 기본값을 `false` 로 뒀습니다. 켠 뒤 대상이 안 잡히면 이것부터 다시 꺼보세요.

## 안 될 때

**1단계 — Output 창을 엽니다.** Studio 상단 `View` → `Output`.

스크립트가 제대로 실행되면 이 줄이 찍힙니다.

```
[AimAssist] 로드됨 - Q 키 또는 화면 오른쪽 위 패널의 ON 버튼으로 켜세요.
```

| 증상 | 원인과 해결 |
|------|------------|
| 이 줄이 안 찍히고 패널도 안 뜸 | 스크립트가 아예 실행되지 않은 것입니다. ① `Script` 가 아니라 **`LocalScript`** 여야 합니다. ② 위치가 **`StarterPlayer` → `StarterPlayerScripts`** 여야 합니다. `Workspace` 나 `ServerScriptService` 에 넣으면 LocalScript는 실행되지 않습니다. |
| `LocalPlayer가 없습니다` 경고 | 서버 스크립트로 실행됐습니다. 위와 같습니다. |

**2단계 — 패널의 상태 문구를 읽습니다.** 대상을 못 잡으면 이유가 그대로 표시됩니다.

| 상태 문구 | 뜻 |
|----------|-----|
| `우클릭하는 동안 조준` | 정상입니다. 기능은 켜져 있고, **우클릭을 누르면** 조준됩니다. |
| `다른 플레이어 없음` | **혼자 플레이 중입니다.** 가장 흔한 원인입니다. Studio 상단 `Test` 탭 → `Clients and Servers` 에서 플레이어를 **2명 이상**으로 놓고 `Start` 하세요. |
| `같은 팀만 있음` | 팀이 같아서 제외됐습니다. `TeamCheck` 를 `false` 로 바꾸세요. |
| `사거리 밖 (N명)` | `MaxDistance` (기본 300스터드)를 늘리세요. |
| `벽에 가림 (N명)` | `WallCheck` 를 `false` 로 바꾸세요. |
| `살아있는 대상 없음` | 상대가 죽어 있거나 아직 스폰 전입니다. |

더 자세히 보려면 `Debug` 를 `true` 로 바꾸세요. 탐색할 때마다 후보가 몇 명이고 왜 걸러졌는지 Output에 찍힙니다.

## 검증

Roblox API를 모의 구현해서, 스튜디오 없이 스크립트를 실제로 실행해 확인하는 테스트가 들어 있습니다.

```sh
cd roblox/test
LUAU=/경로/luau ./run.sh
```

[luau 릴리스](https://github.com/luau-lang/luau/releases)에서 받은 인터프리터가 필요합니다. 기본 설정과 `WallCheck = true` 두 가지로 각각 돌려서 **총 110개**를 검사합니다.

| 파일 | 역할 |
|------|------|
| `mock.lua` | `Instance` / `CFrame` / `Vector3` / `Enum` / `RaycastParams` 등 Roblox API 모의 구현. `CFrame` 은 회전 행렬까지 실제로 계산합니다 |
| `world.lua` | 플레이어·카메라·렌더스텝이 있는 가상 게임. **우선순위 200에서 카메라를 딴 데로 돌리는 가짜 기본 카메라**를 함께 등록해서, 우리 조준이 그걸 이기는지 확인합니다 |
| `tests.lua` | 시나리오. 프레임을 돌린 뒤 `Camera.CFrame.LookVector` 가 실제로 대상 머리 방향과 일치하는지 벡터로 비교합니다 |

검사하는 것: UI 생성과 우측 상단 배치 / Q 토글과 렌더스텝 등록·해제 / 기본 카메라를 이기고 조준되는지 / **우클릭을 안 누르면 카메라를 건드리지 않고, 누른 첫 프레임에 조준되고, 놓으면 즉시 복귀하는지** / 더 가까운 적이 나타나도 대상을 유지하는지 / 사망·리스폰·퇴장·거리 초과 시 놓아주는지 / 팀·벽·사거리 진단 문구 / 마우스 없는 기기 대체 동작 / 대상을 잡고 있는 동안 레이캐스트를 돌리지 않는지.

## 동작 방식

- **조준 시점** — `UserInputService:IsMouseButtonPressed` 로 매 프레임 우클릭 눌림 상태를 직접 읽습니다. `InputBegan`/`InputEnded` 로 직접 세면 창 밖으로 나갔다 오거나 alt+tab 했을 때 눌린 채로 남는 경우가 있어서 폴링이 더 안전합니다. 누르지 않은 동안은 카메라도 안 건드리고 대상 탐색도 하지 않습니다. 마우스가 없는 기기(`UserInputService.MouseEnabled == false`, 모바일 등)에서는 우클릭이 불가능하므로 ON인 동안 계속 조준합니다.
- **조준 기준점** — 거리 계산도 벽 판정 레이캐스트도 전부 **내 카메라 위치**에서 출발합니다. 캐릭터가 아니라 카메라 기준이라 3인칭에서 보이는 대로 조준됩니다.
- **대상 선정** — 대상이 없을 때만 `Players:GetPlayers()` 를 훑어서, 살아있고(`Humanoid.Health > 0`) 팀·거리(`MaxDistance`)·시야 조건을 통과하는 플레이어 중 카메라에서 가장 가까운 쪽을 고릅니다. 탐색은 플레이어 수만큼 레이캐스트를 돌리므로 0.15초 주기로 제한합니다.
- **대상 유지** — 한 번 잡은 대상은 **계속** 따라갑니다. 더 가까운 사람이 나타나도 갈아타지 않습니다. 놓아주는 조건은 세 가지뿐입니다 — 게임을 나갔거나, 죽었거나(리스폰 포함), `DropDistance` 보다 멀어졌을 때. 팀과 벽 여부는 유지 판정에서 보지 않으므로 대상이 엄폐물 뒤로 숨어도 조준이 풀리지 않습니다. 대상을 놓친 프레임에는 곧바로 다음 대상을 찾습니다.
- **조준** — `RunService:BindToRenderStep` 을 기본 카메라(우선순위 `200`)보다 **뒤인 `210`** 에 등록해서, 기본 카메라가 `CFrame` 을 쓴 다음 우리가 덮어씁니다. `+10` 은 다른 카메라 스크립트가 `201` 을 쓰고 있을 경우를 대비한 여유입니다.
- **위치 vs 회전** — 카메라 *위치* 는 기본 카메라가 계산한 값을 그대로 써서 캐릭터를 자연스럽게 따라가게 하고, *회전* 만 별도 상태(`aimRotation`)로 들고 목표 쪽으로 보간합니다. 기본 카메라의 `CFrame` 에서 매 프레임 보간을 다시 시작하면 조준이 목표까지 수렴하지 못하기 때문입니다.
- **조준 속도** — 기본값 `Smoothness = 0` 이면 보간 없이 매 프레임 목표 회전으로 바로 스냅합니다. `0` 보다 크게 주면 `1 - math.exp(-Smoothness * deltaTime)` 로 보간해서, 프레임레이트가 달라져도 따라붙는 속도가 같습니다.
- **시야 판정** — `workspace:Raycast` 로 카메라와 대상 사이에 막힌 게 있는지 확인하고, 내 캐릭터와 대상 캐릭터는 필터에서 제외합니다. 새 대상을 고를 때만 씁니다.
